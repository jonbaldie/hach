# Canonical Project Name Hach

We chose `hach` (Haskell Agentic Coding Harness) as the canonical name for the project, repository, Cabal package, and CLI binary. While `hatch` was considered for natural English phrasing, it collides directly with Python's official packaging tool in Homebrew Core (`brew install hatch`), which would cause PATH collisions on macOS systems. `hach` is completely unique across Homebrew, Hackage, and GitHub while preserving the exact acronym.
